# Blue River Glades RFP Map

Interactive map of the three Jackson County parcels in the Blue River Glades RFP
(7701–7711 Blue River Rd, Kansas City, MO), with mapped trails, aerial imagery,
LiDAR relief and a georeferenced Strava heatmap screenshot.

Static site: open `index.html`, or view it on GitHub Pages.

## Data sources

- Parcels: Jackson County GIS (ParcelsAscendRelate service)
- Trails: © OpenStreetMap contributors, ODbL (pulled Oct 31 2026)
- Aerial: USDA NAIP via USGS National Map (public domain)
- Relief: USGS 3DEP LiDAR hillshade (public domain)
- Heat: Strava Global Heatmap screenshot (reference only)
